# Release status

Current status: **Candidate** — E2E fine-tuning tutorial source complete, awaiting supported clean-runtime execution. The pipeline package, 62 offline unit tests (including the notebook-parity tests) plus 3 model-backed tests, one executed local CPU run of the committed notebook blob, `MODEL_CARD.md`, and the standalone `E2E` tutorial `tutorials/mace_materials_colab.ipynb` (generated by `tools/build_notebook.py`, DIMER Notebook Specification 2.0 §4) exist and pass static validation (`tools/validate_release_assets.py`, including the generator parity checks). Unit tests and static conformance checks run in GitHub Actions. The tutorial remains non-release-grade until clean-runtime execution evidence from a supported hosted runtime for the exact candidate commit is recorded according to `docs/release-verification.md`.

No licence or remote-code gate is open for DIMER hosting (MIT weights; the model class comes from `mace-torch` on PyPI). One review item is open on the asset side: the upstream `.model` file is a pickle, which this repository audits statically and converts once into a digest-pinned safetensors + JSON pair that is the only artifact the runtime path loads. Whether that one-time audited unpickle (in the build, and in the tutorial runtime) meets the DIMER deserialization-trust bar — or whether DIMER should host only a pair converted and verified once by the maintainer — is the maintainer's call. See `MODEL_CARD.md` (*DIMER deployment notes*) and `docs/WEIGHTS.md`.
